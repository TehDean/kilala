# Kilala

A private map of who knows who in the friend group, built to help friend groups mix.

- Friends join with a personal invite link and sign in with an email link (or Google).
- The map shows everyone and their connections; a link counts once both people confirm it (or Dean vouches for it until they answer).
- Ranks: new connections this month, top connector (intros that stuck), bridge builder (connecting separate groups).
- Events (Dean only): guest list, suggested intros, and a checklist for the night.

Data lives in Supabase (Playground 1, `kilala_*` tables). Database setup: `supabase/setup.sql`.
